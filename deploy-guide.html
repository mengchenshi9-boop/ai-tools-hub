🚀 三种部署方式（任选其一）

📌 方式一：上传文件夹（最简单）

1. 访问 https://vercel.com/new
2. 点击 "Upload" 标签页
3. 拖拽整个 ai-tools-nav 文件夹
4. 点击 "Deploy"
5. 等待 1-2 分钟
6. ✅ 完成！获得 xxx.vercel.app 链接

📌 方式二：GitHub + Vercel（推荐）

1. 访问 https://github.com/new 创建仓库
2. 仓库名：ai-tools-hub
3. 推送到 GitHub：
git remote add origin https://github.com/你的用户名/ai-tools-hub.git
git push -u origin main
4. 访问 https://vercel.com/new
5. 导入 GitHub 仓库
6. 点击 "Deploy"

📌 方式三：Vercel CLI（最专业）

1. 安装：npm install -g vercel
2. 登录：vercel login
3. 部署：vercel
