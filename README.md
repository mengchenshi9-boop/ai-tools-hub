## 🌐 部署方式

### 方式一：Vercel（推荐）

1. 将代码推送到 GitHub
2. 登录 [vercel.com](https://vercel.com)
3. 导入项目，一键部署
4. 自动获得 `xxx.vercel.app` 域名

### 方式二：Cloudflare Pages

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com)
2. 创建 Pages 项目
3. 上传 `index.html`
4. 获得 `xxx.pages.dev` 域名

### 方式三：GitHub Pages

1. 创建 GitHub 仓库
2. 上传代码
3. 设置 → Pages → 选择分支
4. 获得 `xxx.github.io` 域名
